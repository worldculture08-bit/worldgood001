“무료로 시작”과 “우리 팀이 계속 무료로 쓸 수 있음”은 다른 말입니다. 개인 기준으로는 충분한 한도가 팀 기준으로는 하루 만에 바닥나기도 합니다. 이 글은 무료와 유료를 **업무 기준**으로 비교하는 순서를 정리합니다.

## 무료 요금제가 부족해지는 순간

무료 한도는 보통 세 곳에서 걸립니다.

1. **사용량** — 하루·월 대화 수, 파일 업로드 수, 입력 길이
2. **기능** — 긴 문서, 파일 분석, 화자 구분, 검색이 유료 전용
3. **관리** — 권한·감사·중앙 관리가 없음

개인은 1번에서, 팀은 대개 **3번**에서 막힙니다.

## 판단 기준 1: 한도를 팀 기준으로 다시 계산한다

무료 한도를 사람 수로 나눠 봅니다.

```
1인당 하루 사용 가능량 = 무료 한도 ÷ 인원
```

무료 한도가 “하루 N회”라면, 10명 팀에서는 1인당 N/10회입니다. 그 수치가 실제 업무량보다 적으면 유료가 필요합니다. 이 계산 없이 “무료로 되겠지” 하고 시작하면 일주일 안에 다시 결정해야 합니다.

## 판단 기준 2: 막히는 기능이 핵심 업무인가

유료 전용 기능이 **우리 업무의 핵심**이면 무료는 의미가 없습니다.

| 기능 | 무료 | 우리 업무에서의 비중 |
|---|---|---|
| 긴 문서 입력 | 제한 | 계약서·보고서를 다룬다면 핵심 |
| 파일 분석 | 제한 | 표·자료를 다룬다면 핵심 |
| 검색·출처 | 제한 | 최신 정보를 다룬다면 핵심 |
| 관리자 통제 | 없음 | 조직 도입이면 필수 |

표를 채우면 “무료로 충분한가”가 거의 자동으로 나옵니다.

## 판단 기준 3: 데이터 정책

무료 요금제는 **입력 데이터를 학습에 사용**하는 경우가 많습니다. 업무 문서·고객 정보를 넣는다면 이 항목만으로 유료가 필요할 수 있습니다. 확인할 것:

- 학습 사용 여부, 끌 수 있는지
- 보관 기간
- 삭제·내보내기
- 관리자 접근 통제

기준은 [AI 업무에서 개인정보를 다루는 방법](/p/privacy-in-ai-work)을 참고하세요.

## 판단 기준 4: 관리자·권한 기능

팀 도입이면 무료로는 대개 부족합니다.

- 계정 추가·삭제를 중앙에서 하는가
- 누가 무엇을 썼는지 기록이 남는가
- 퇴사자 계정을 정리할 수 있는가
- 결제를 한 곳에서 관리하는가

이 기능이 없으면 사람이 손으로 관리해야 하고, 그 시간이 요금보다 커집니다.

## 판단 기준 5: 초과 과금 구조

사용량 기반 요금제는 **초과 청구**가 위험합니다.

- 한도 초과 시 어떻게 청구되는가
- 상한을 정할 수 있는가
- 예상치 못한 급증을 막는 알림이 있는가

정액 요금제는 예측이 쉽고, 사용량 요금제는 싸게 시작하지만 상한 관리가 필요합니다. 예산 담당자와 **월 상한**을 정해 둡니다.

## 무료 → 유료 전환 시점

다음 중 하나면 전환을 검토합니다.

- 팀 기준 한도가 1주일 안에 소진된다
- 핵심 업무가 유료 기능에 막혀 있다
- 업무 데이터를 넣어야 하는데 학습 정책이 걸린다
- 관리자 통제 없이 계정이 늘어난다

반대로 다음이면 무료를 유지합니다.

- 반복 업무가 적다
- 검증할 사람이 없다
- 민감 데이터를 넣을 일이 없다

## 전환 전 실험

바로 팀 전체로 가지 않습니다.

1. 업무가 많은 사람 10~20%만 유료로 시작한다.
2. 1개월간 절약 시간과 오류를 기록한다.
3. 순효과가 요금보다 큰지 확인한다.
4. 확대·유지·중단을 정한다.

계산 방법은 [사용자당 AI 도구 ROI 계산](/p/copilot-roi-calculation)에 있습니다.

## 자주 하는 실수

- 개인 기준 한도로 팀 도입을 판단한다
- 학습 정책을 확인하지 않는다
- 초과 과금 상한을 정하지 않는다
- 전원 유료로 시작한다
- 무료와 유료를 동시에 굴려 요금이 겹친다

## 체크리스트

- [ ] 무료 한도를 인원으로 나눠 계산했다
- [ ] 유료 전용 기능이 핵심 업무인지 확인했다
- [ ] 학습·보관·삭제 정책을 확인했다
- [ ] 관리자 기능 필요 여부를 정했다
- [ ] 초과 과금 상한을 정했다
- [ ] 전환 실험 대상을 정했다
