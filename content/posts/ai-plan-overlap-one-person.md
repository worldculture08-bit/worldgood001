기준일 2026년 9월 24일. 금액은 미국 달러 공개 요금이다. 한국 카드 결제, 부가세, 연간 할인, 기간 한정 프로모션은 각 결제 화면이 이 표보다 우선한다. 한 사람의 개인 구독만 비교한다.

## 적용 대상

글을 쓰고 문서를 읽고 질문을 던지는 용도로, 아래 네 가지를 각자 결제할지 보는 경우다. API 종량 요금, 팀 최소 인원, GitHub Copilot은 넣지 않았다. GitHub Copilot은 코드 편집기 구독이라 Microsoft 365 Copilot과 다른 상품이다.

2026년 9월 공개된 개인·1인 자리 가격:

| 상품 | 월 요금 | 하는 일 |
|---|---|---|
| ChatGPT Plus | 20달러 | 범용 대화, 파일, 음성 |
| Claude Pro | 20달러. 연간 결제면 월 환산 17달러 | 긴 문서, 같은 회사의 코드 도구와 사용량 공유 |
| Google AI Pro | 19.99달러 | Gemini와 Google 저장공간·문서 |
| Microsoft 365 Premium | 19.99달러 | 소비자용 Microsoft 365에 Copilot이 들어간 상품 |

회사 파일용 Microsoft 365 Copilot Business는 1인 추가 상품이 아니다. 이미 Microsoft 365 사업자 요금제가 있어야 하고, 2026년 9월 연간 약정 정가는 사용자당 월 21달러, 2026년 12월 31일까지 첫해 프로모션은 월 18달러, 월 단위는 25.20달러다. 이 돈은 오피스 요금 위에 더해진다.

## 공식

한 달 겹침 = 실제로 켜 둔 구독의 월 요금 합

같은 일을 하는 구독이 둘이면 하나는 겹침이다. 글쓰기·질문·요약만 하면 Plus, Pro, AI Pro 셋은 같은 자리다. 파일함이 구글에만 있으면 AI Pro, 워드·엑셀·아웃룩 안에 있으면 Copilot, 긴 문서를 한 회사에서 끝까지 다루면 Claude가 남는 이유가 된다.

## 예시

네 개인 상품을 모두 월간 결제하면 20 + 20 + 19.99 + 19.99 = 79.98달러다. 글쓰기만 하고 파일은 어느 한쪽에만 있으면 20달러 전후 하나면 된다. 오피스 파일까지 다루면 챗 하나(20달러)에 Microsoft 365 Premium 19.99달러를 더해 39.99달러다. 회사에 Copilot Business를 더 얹으면 오피스 기본료까지 포함해 다시 계산한다. 챗 구독 세 개에 Copilot까지 둔 79.98달러는 같은 질문을 네 번 사는 구조다.

## 출처

2026년 9월 23–24일 각 사 요금 페이지를 옮긴 비교표. ChatGPT Plus 20달러, Claude Pro 20달러(연간 환산 17달러), Google AI Pro 19.99달러, Microsoft 365 Premium 19.99달러, Microsoft 365 Copilot Business 연간 21달러·첫해 프로모션 18달러(2026.7.1.–12.31., 기존 Business 고객, 연간 약정). 결제 직전 화면의 통화와 세금이 최종 금액이다.
